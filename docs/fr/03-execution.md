# 3. Exécution et Engine API

Reth reçoit les blocs et ordres d’exécution du consensus layer via l’Engine API, puis applique les règles Ethereum dans son environnement d’exécution.

La compatibilité avec les clients de consensus est donc un contrat d’interface autant qu’un mécanisme de synchronisation.
