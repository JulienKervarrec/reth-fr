# 1. Vue d’ensemble de Reth

Reth est un client d’exécution Ethereum en Rust, modulaire et orienté performance. Il est compatible avec les clients de consensus via l’Engine API.

Le dépôt est organisé autour de crates réutilisables, d’un binaire, de la documentation et de profils adaptés aux opérateurs de nœuds.
