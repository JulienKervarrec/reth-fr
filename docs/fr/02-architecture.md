# 2. Architecture par composants

La modularité est le choix central : chaque composant peut être utilisé comme bibliothèque, documenté et benchmarké. Les dossiers crates et docs décrivent les frontières entre réseau, exécution, stockage et interfaces.

Cette composition permet d’adapter le client à Ethereum ou à d’autres chaînes EVM, tout en conservant un noyau commun.
