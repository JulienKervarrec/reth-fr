# 4. Stockage et migrations

Le dépôt distingue les formats de stockage et prévoit une évolution vers Storage V2. La base historique, les snapshots et la séparation possible des données influencent directement les coûts opérateur.

Une migration de format doit être considérée comme une étape de fiabilité : compatibilité, récupération et version des données sont aussi importantes que la vitesse de lecture.
