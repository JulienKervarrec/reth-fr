# 5. Performance et profils opérateur

Reth vise les RPC, l’indexation, le MEV, les simulations et les activités P2P à forte exigence. Les benchmarks et profils permettent de choisir entre débit, empreinte disque et matériel disponible.

La performance n’est pas isolée du modèle de données : les optimisations de stockage et de synchronisation participent au résultat global.
